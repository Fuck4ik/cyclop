# Диктовка в Cyclop

Перенос голосовой диктовки из отдельного приложения WhisperDictation внутрь
Cyclop, с историей расшифровок во вкладке панели и починкой расхода памяти.

## Зачем

Диктовка и челка — два инструмента, которые уже стоят рядом на одной машине, и
разделены только тем, что писались порознь. Отдельное приложение стоит второй
иконки в меню-баре, второго инсталлятора и постоянных 3.3 ГБ оперативной памяти.
Ни одно из трёх не окупается.

Вдобавок расшифровки нигде не сохраняются: текст вставляется в поле под курсором
и забывается навсегда. На диске остаются только `.wav` и лог, в котором от каждой
диктовки записаны первые 80 символов. Диктовка, ушедшая не в то окно, потеряна.

## Что решено, и на основании чего

### Движок остаётся прежним

`mlx-whisper` с моделью `mlx-community/whisper-large-v3-turbo` — не по инерции, а
потому что три альтернативы были проверены на реальных записях и проиграли.

Эталон снят перепрогоном 12 записей длиной от 0.6 до 140 с через нынешний движок
с его собственным конфигом. Все 12 совпали с тем, что тогда было вставлено в
текст, — движок детерминирован, и сравнивать с ним можно.

| Реализация | Тот же MLX | `initial_prompt` | Термины на записи с 12 англицизмами |
|---|---|---|---|
| **mlx-whisper (Python)** | да | **да** | все |
| mlx-audio-swift | да, те же веса | нет в API | — |
| WhisperKit (Core ML) | нет | не работает | 8 из 12 потеряно |
| whisper.cpp | нет | да | `CICD`→`ICD`, `U-Track`→`U-`, `Cloud Code` и `Codex` пропали |

Промпт на 1100 символов со словарём технических терминов — не украшение, а то,
что удерживает `GitHub`, `CICD`, `Codex` в латинице вместо кириллической
транслитерации. Единственная реализация Whisper на MLX, принимающая его, —
питонья. Отсюда и Python в архитектуре: он остаётся ровно в одной роли —
считать модель.

Замеры для полноты: WhisperKit без промпта даёт CER 2.1% против эталона, то есть
сам по себе хорош, но требует 2+ минут компиляции ANE при первом запуске и молча
возвращает пустоту на записях короче секунды. whisper.cpp зациклился на одной из
12 записей и потерял треть текста.

### Память: 3.3 ГБ → ~50 МБ в покое

Замерено, а не оценено: веса модели занимают 1543 МБ, кэш аллокатора MLX — 1986 МБ.
Второе освобождается вызовом `mx.clear_cache()` мгновенно и без последствий.

| Мера | Освобождает |
|---|---|
| `mx.clear_cache()` после каждой диктовки | 1986 МБ |
| Выгрузка модели после 10 минут простоя | 1543 МБ |
| Прогрев при первом нажатии, а не при запуске | всё до первой диктовки |

Плата — первая диктовка после долгой паузы медленнее на 2–4 с, пока модель
грузится обратно. Выбрано сознательно: приложение простаивает несравнимо дольше,
чем работает.

Прогрев нельзя убрать совсем: он существует не ради скорости, а чтобы Metal
инициализировался до первого рендера панели, иначе процесс падает с
`no Stream(gpu, 1)`. Он переносится на первое нажатие хоткея, а не отменяется.

### Производительность: убрать тройное обращение к диску

Сейчас каждая диктовка пишет `.wav`, перечитывает его для нормализации,
переписывает и читает третий раз в транскрайбере. Аудио уже лежит в памяти —
модель принимает массив напрямую (`warm_up` в нынешнем коде так и делает). Диск
остаётся только для архива, вне критического пути.

## Архитектура

```
Cyclop.app
├── Swift
│   ├── HotkeyMonitor        правый ⌥, push-to-talk, порог 0.25 с
│   ├── AudioRecorder        AVAudioEngine, 16 кГц моно, пик → −3 dBFS
│   ├── TranscriberBridge    воркер по stdin/stdout, построчный JSON
│   ├── TextInserter         буфер обмена + ⌘V
│   ├── DictationHistory     чтение и запись history.jsonl
│   └── DictationPane        вкладка: поиск, копирование, воспроизведение
└── Resources/worker/        Python: transcriber, audio_processor,
                             text_cleaner, config — без единой правки
```

`TranscriberBridge` строится по образцу `NowPlayingFeed`: тот уже держит
внешний процесс (perl с хелпером), читает построчный JSON из его stdout,
перезапускает при падении и умирает вместе с приложением. Здесь то же самое,
только процесс — Python.

### Протокол воркера

Запрос и ответ — по строке JSON:

```
-> {"cmd": "transcribe", "path": "/tmp/dictation-xxx.wav"}
<- {"text": "…", "took": 1.2, "language": "ru"}
-> {"cmd": "unload"}
<- {"unloaded": true, "freed_mb": 3529}
```

Воркер завершается, когда закрывается его stdin, — пережить Cyclop он не может.

### История

`~/Library/Application Support/Cyclop/dictation-history.jsonl`, по записи на
строку:

```json
{"at":"2026-08-05T17:34:04Z","text":"…","chars":630,"audio":"dictation-20260805-173404.wav","took":11.05,"model":"mlx-community/whisper-large-v3-turbo"}
```

JSONL, а не JSON-массив: запись дописывается в конец одной операцией, файл
переживает падение на середине, и его можно читать и править руками — ровно как
`snippets.json`, который в этом приложении уже так устроен.

Вкладка повторяет дисциплину соседних: поиск по всем записям (как в
«Заготовках»), клик кладёт текст в буфер обмена (как в «Буфере»), рядом кнопка
воспроизведения исходного `.wav`.

Ретенция: 500 записей в файле. Аудио не удаляется никогда — папка принадлежит
пользователю, как и `~/Pictures/Cyclop` у скриншотов.

### Заполнение архивом

155 накопленных записей перетранскрибируются разово тем же движком и тем же
конфигом. При 22× реального времени это минуты, и история наполняется с первого
дня, а не с первой новой диктовки.

## Разрешения

Cyclop перестаёт быть приложением без разрешений. Нужны два:

- **Микрофон** — запись;
- **Универсальный доступ** — глобальный хоткей и вставка текста.

Оба запрашиваются при первой диктовке, а не при запуске: остальные шесть вкладок
работают без них, и человек, который поставил Cyclop ради полки и буфера, не
должен видеть системный диалог вовсе. Календарь уже устроен так же.

## Что ломается и что с этим делать

**Конфликт хоткея.** Пока оба приложения живы, они дерутся за правый ⌥.
WhisperDictation убирается из автозапуска в тот момент, когда диктовка в Cyclop
заработает, — не раньше.

**Панель как индикатор.** Индикатор записи переезжает в челку вместо нынешнего
плавающего окна. Панель раскрывается на время записи принудительно и не
закрывается по уходу курсора, пока идёт запись или расшифровка, — иначе
состояние пропадает из виду в середине фразы.

**Размер бандла.** Приложение перестаёт быть 1.2 МБ. Способ упаковки Python —
запечь рантайм в бандл или ставить при первом запуске — решается отдельно, когда
дойдёт до раздачи; до тех пор воркер берётся из уже существующего venv.

## Границы

Не входит в эту работу: смена модели, тюнинг промпта, стриминговая расшифровка
по ходу речи, синхронизация истории между машинами, удаление старых `.wav`.
