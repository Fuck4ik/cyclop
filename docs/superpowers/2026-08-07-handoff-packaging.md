Написано в конце сессии 2026-08-06/07, когда диктовка уже работает, а раздача
ещё нет. Документ самодостаточен: продолжать можно, не читая прежнюю переписку.

- Репозиторий: `~/www/cyclop`, форк `Fuck4ik/cyclop` (апстрим `akalikbergenov/cyclop`).
- Ветка `dictation`, **не запушена**. ~35 коммитов поверх `a8f5bb2`.

- Разрешения (микрофон, Универсальный доступ) выданы и переживают пересборку —

- Прежнее приложение `/Applications/WhisperDictation.app` выключено (процессы
  сняты, автозапуска у него не было). Не удалено: оно откат и источник venv.

## Что уже работает

Голосовая диктовка внутри Cyclop: правый ⌥ как рация, распознавание локальным
mlx-whisper через Python-воркер, вставка текста под курсор, история расшифровок
седьмой вкладкой (поиск, копирование, прослушивание), анимация под челкой.

Тесты: 48 XCTest + 10 тестов воркера, все зелёные. Сборка без предупреждений.

Ключевые файлы:

```
Sources/CyclopDictation/     тестируемая логика (история, протокол, звук, жест)
Sources/Cyclop/Dictation/    хоткей, запись, мост к воркеру, контроллер, вставка
Sources/Cyclop/UI/Dictation* вкладка истории, две анимации, стиль и настроение
Resources/worker/            cyclop_worker.py + его тесты
Scripts/bundle.sh            сборка .app вручную, подпись, копирование воркера
```

Память диктовки в покое: 165–171 МБ против 3254 МБ у прежнего приложения
(замеры и методика — `docs/dictation-memory.md`).

## Что делаем дальше

Цель: отдать приложение другу (такой же Apple Silicon Mac) так, чтобы у него
всё заработало. Четыре этапа, первые два обязательны.

### 1. Отвязать воркер от WhisperDictation

Сейчас `Resources/worker/cyclop_worker.py` импортирует
`whisper_dictation.config`, `.transcriber`, `.text_cleaner` из venv прежнего
приложения. У друга этого нет — диктовка не запустится вовсе.

Исходники лежат в `/Applications/WhisperDictation.app/Contents/Resources/app/src/whisper_dictation/`,
лицензия **MIT** (`pyproject.toml`), автор Sergej — копировать можно, указав
происхождение. Нужны ровно четыре модуля: `config.py` (там промпт на 1100
символов и параметры декодирования), `transcriber.py`, `text_cleaner.py`,
`model_catalog.py`. Всё остальное (`recorder`, `hotkey`, `inserter`,
`indicator`, `menu_bar`, `app`) не нужно — это делает Swift.

Осторожно: `config.load_config()` вызывает `ensure_dirs()` и создаёт папки
прежнего приложения; при переносе это надо убрать, свои пути — в
`~/Library/Application Support/Cyclop/`.

**Настройки распознавания трогать нельзя.** Промпт, `temperature = 0`,
`condition_on_previous_text = false`, автоопределение языка — они подобраны и
проверены: расшифровка совпала с историей посимвольно на записи в 1774 знака.

### 2. Запечь рантайм в бандл

Проверено в этой сессии, спайк успешен:

```bash
uv venv --relocatable --python 3.11 --python-preference managed .venv
uv pip install --python .venv/bin/python mlx-whisper
```

Окружение **переносимо**: физически переместил папку и `import mlx_whisper`
продолжил работать. `uv` версии 0.9.17 стоит из Homebrew.

Размеры установленного (site-packages, 972 МБ всего):

| Пакет | МБ | Нужен? |

| mlx | 186 | да |

**Не проверено:** соберётся ли рабочее окружение без torch — попробовать

Путь к интерпретатору сейчас зашит в `TranscriberBridge.swift:38-45` (venv

### 3. Каталог моделей и прогресс скачивания

Решения владельца, приняты в этой сессии:

- **Где:** во вкладке диктовки, там же, где сейчас экран разрешений. Нет
  модели — список с размерами и кнопкой, затем полоса загрузки, затем история.
  Новых экранов и окон не заводить.
- **Первый запуск:** если зажали клавишу, а модели нет — записывать звук всё
  равно, параллельно качать модель по умолчанию, и вставить текст, когда
  докачается. Первая фраза не должна пропасть.
- **Модели:** четыре, как в `model_catalog.py` прежнего приложения —
  `large-v3-turbo` (1.5 ГБ, нынешняя), `large-v3` (точнее, медленнее),
  `large-v3-turbo-q4` (442 МБ, почти та же точность), `small` (для слабых
  машин).

Как получать прогресс — проверено: `huggingface_hub.snapshot_download`
принимает параметр **`tqdm_class`**. Подставить свой класс, который вместо
рисования полосы шлёт в stdout строки вида
`{"progress": 0.42, "downloaded_mb": 630, "total_mb": 1500}`. Swift-сторона уже
умеет читать построчный JSON (`WorkerProtocol`, `TranscriberBridge`).

`mlx_whisper.load_models.load_model` зовёт `snapshot_download(repo_id=...)` без
параметров, так что качать надо своей командой воркера **до** первой
транскрибации, а не перехватывать вызов внутри библиотеки.

Уже скачано на этой машине (`~/.cache/huggingface/hub/`): `large-v3-turbo`
(1.5 ГБ) и `large-v3-turbo-q4` (442 МБ). Для проверки прогресса на чистой
загрузке брать `small` или `large-v3`.

### 4. Образ и публикация

- `Scripts/dmg.sh` в проекте уже есть (из апстрима): собирает
  `build/Cyclop-<версия>.dmg` с ярлыком `/Applications`, версия из
  `Scripts/version`.
- GitHub Actions на macOS-раннере arm64: собрать, упаковать, опубликовать в
  Releases по тегу. Репозиторий публичный — минуты бесплатны.
- Подпись в CI будет ad-hoc (сертификата там нет), поэтому другу понадобится
  один раз снять карантин: `xattr -dr com.apple.quarantine /Applications/Cyclop.app`
  или «Всё равно открыть» в Системных настройках. README апстрима это уже
  описывает — дополнить своим случаем.
- Developer ID и нотаризация ($99/год) — если захочется установки вообще без
  предупреждений. Тогда сертификат и app-specific password в секретах.

## Грабли этого проекта

Собраны дорогой ценой, каждая стоила отдельного раунда ревью.

- **`@Published` рассылает подписчикам синхронно, в `willSet`, когда в
  хранилище ещё старое значение.** На этом трижды строились дефекты: залипание
  клавиатуры, запирание записи, порядок двух строк в `NotchViewModel`. Любую
  правку вокруг состояния диктовки проверять трассировкой графа вызовов, а не
  только тестами: тесты живут в `CyclopDictation` и исполняемый таргет не видят.
- **Ad-hoc подпись меняется каждую сборку**, и macOS считает приложение новым,
  отзывая выданные разрешения при внешне включённом тумблере. Поэтому
  `bundle.sh` подписывает сертификатом разработчика, если он есть. В CI его нет
  — там ad-hoc, и это нормально, но у друга разрешения слетят при каждом
  обновлении. Стоит написать об этом в README.
- **Canvas обрезает по своим границам.** Размытое свечение, дотянувшееся до
  края, срезается ровной линией. Холст всегда крупнее рисунка.
- **Затухание должно гасить яркость, а не только размах** — иначе по краям
  анимации остаются прямые неподвижные линии.
- Файл истории `~/Library/Application Support/Cyclop/dictation-history.jsonl`
  содержит 155 записей, у каждой поле `source`, которого нет в модели. Запись
  идёт дозаписью одной строки через `O_APPEND` — полная перезапись стёрла бы
  эти поля (уже ловили).

## Команды

```bash
cd ~/www/cyclop
swift build && swift test                          # 48 тестов
python3 Resources/worker/test_cyclop_worker.py     # 10 тестов
./Scripts/bundle.sh release                        # собрать .app
rm -rf /Applications/Cyclop.app && cp -R build/Cyclop.app /Applications/
```

Проверить, что хоткей слышен, не нажимая клавишу руками: послать системе
`flagsChanged` с кодом 61 и битом `0x40` (правый Option), затем убедиться, что
поднялся `cyclop_worker` (`pgrep -fl cyclop_worker`).

Логи приложения: `log stream --predicate 'process == "Cyclop"'` — туда же
попадает stderr воркера.
