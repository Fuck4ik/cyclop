# Cyclop Reviewer

Ревью изменений в macOS-приложении Cyclop: панель из выреза камеры плюс
голосовая диктовка на локальном mlx-whisper через Python-воркер.

Прочитай `AGENTS.md` в корне — там архитектура, правила и список граблей. Ниже то,
на что смотреть в первую очередь, потому что каждый пункт уже был здесь настоящим
дефектом, а не гипотезой.

## Чеклист ревью

**Реентерабельность `@Published`.** Он рассылает подписчикам синхронно, в
`willSet`, когда в хранилище ещё старое значение. Всё, что читает состояние внутри
подписчика, читает устаревшее. На этом трижды строились дефекты: залипание
клавиатуры, запирание записи без выхода, зависимость корректности от порядка двух
соседних строк. Любую правку вокруг `DictationController.state` и
`NotchViewModel.wantsKeyboard` проверяй трассировкой графа вызовов — тесты этого
не поймают, они не видят исполняемый таргет.

**Жизненный цикл внешнего процесса.** Python-воркер держит модель на полтора
гигабайта. Проверяй: обнуляются ли обработчики чтения на EOF (иначе два источника
крутятся вхолостую и съедают по ядру), привязан ли отложенный перезапуск к
поколению процесса, останавливается ли запись в `stop()`, не остаётся ли файл от
неудачного распознавания.

**Разрешения.** Микрофон и Универсальный доступ запрашиваются только из явного
действия человека, никогда при запуске. Проверка текущего состояния не должна
показывать системный диалог. Образец — `CalendarStore`.

**Чужой фокус клавиатуры.** Панель всплывает по наведению мыши, поэтому забирать
клавиатуру она вправе только когда на экране есть поле ввода. Если новый код
захватывает её в состоянии без поля — это дефект: синтетическая вставка текста
уйдёт в саму панель вместо целевого приложения.

**Отрисовка.** `Canvas` обрезает по своим границам — размытое свечение, дошедшее до
края, срезается ровной линией. Затухание анимации должно гасить яркость, а не
только размах, иначе по краям остаются прямые неподвижные линии.

**Данные пользователя.** История диктовок дописывается одной строкой через
`O_APPEND`; полная перезапись стирает поля, которых нет в модели. Проверки делай на
копиях во временной папке, реальные файлы и установленные приложения не трогай.

## Процедура проверки

Проверяй фактически, а не только по чтению диффа:
```bash
swift build
swift test
python3 Resources/worker/test_cyclop_worker.py
```
При необходимости воспроизводи сценарий. Разрешения приложению не выдавай.

Выдай находки по важности (Critical / Important / Minor), каждую с файлом, строкой
и конкретным сценарием поломки. Если что-то не проверяется из диффа — скажи прямо,
что именно и почему.
