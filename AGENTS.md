# AGENTS.md

## Что это за репозиторий

Cyclop — форк [akalikbergenov/cyclop](https://github.com/akalikbergenov/cyclop):
панель, выезжающая из выреза камеры MacBook. Форк добавляет голосовую диктовку:
правый ⌥ работает как рация, распознавание идёт локально, текст вставляется под
курсор, история расшифровок живёт седьмой вкладкой.

Нативное приложение: Swift 6 (языковой режим v5), SwiftUI + AppKit, SwiftPM без
единой внешней зависимости. Распознаванием занимается Python-процесс с
mlx-whisper, которым Swift управляет через stdin/stdout.

## Конфигурация агентов

Репозиторий использует кросс-агентную схему, чтобы Claude Code, Codex, Cursor и
Antigravity читали одни и те же инструкции:

- `AGENTS.md` — канонические инструкции (этот файл). Читается Codex, Cursor и
  Antigravity нативно.
- `CLAUDE.md` — однострочный указатель (`@AGENTS.md`) для Claude Code. Содержимое
  туда не писать, править только `AGENTS.md`.
- `.agents/skills/` — скиллы проекта в формате `SKILL.md`.
- `.claude/skills` — симлинк на `.agents/skills`, чтобы Claude видел те же скиллы.
- `.claude/settings.json` — специфичное для Claude: разрешения и хуки.

## Структура

```
Sources/CyclopDictation/     чистая логика диктовки — единственное, что покрыто тестами
Sources/Cyclop/              приложение: панель, вкладки, службы, интеграция с системой
  ├── Dictation/             хоткей, запись, мост к воркеру, контроллер, вставка
  ├── Notch/                 окно панели, геометрия выреза, слежение за курсором
  ├── Services/              плеер, буфер, полка, календарь, заготовки, перевод
  └── UI/                    вкладки и анимации
Resources/worker/            Python-воркер распознавания и его тесты
  └── cyclop_dictation/      настройки, транскрайбер, чтение wav, каталог и загрузка моделей
Scripts/                     рантайм, сборка .app, образ, релиз
docs/superpowers/            спеки, планы и передача контекста между сессиями
```

Логика живёт в `CyclopDictation`, а не в исполняемом таргете, по одной причине:
SwiftPM не даёт тестам импортировать executable. Всё, что должно быть покрыто
тестами, обязано лежать там.

## Команды

```bash
swift build && swift test                       # 56 тестов Swift
python3 Resources/worker/test_cyclop_worker.py  # 31 тест воркера, без mlx
./Scripts/runtime.sh                            # собрать питон для бандла, ~500 МБ
./Scripts/bundle.sh release                     # собрать .app и подписать
```

Рантайм собирается отдельно и живёт в `.runtime`: пересобирать его нужно
только когда меняется список пакетов, а `bundle.sh` каждый раз просто копирует
то, что там лежит. Один тест воркера — чтение настоящего wav — пропускается на
системном питоне, где нет numpy; полный прогон делается рантаймовым:
`.runtime/bin/python3.11 Resources/worker/test_cyclop_worker.py`.

Скиллы для частых операций: `/build-install` (собрать и поставить в
`/Applications`), `/dictation-probe` (проверить диктовку живьём),
`/localization-check` (сверить строки ru/en).

## Правила

**Комментарии — по-английски**, как во всём репозитории, включая апстрим. Объясняют
причину решения, а не пересказывают код. Сообщения коммитов — по-русски.

**Настройки распознавания неприкосновенны.** Промпт на 1100 символов,
`temperature = 0`, `condition_on_previous_text = false`, автоопределение языка —
подобраны и проверены на реальных записях. Лежат в
`Resources/worker/cyclop_dictation/config.py`, за ними следят тесты. Менять
только по явной просьбе владельца.

**Разрешения запрашиваются по факту использования, не при запуске.** Приложение
сознательно живёт без разрешений, пока человек сам не откроет вкладку, которой
они нужны. Образец дисциплины — `CalendarStore`.

**Чужой фокус клавиатуры — не наш.** Панель забирает клавиатуру только когда на
экране есть поле ввода, и отдаёт при первой возможности: она всплывает по
наведению мыши, и отбирать у активного окна курсор ради этого слишком грубо.

**Файлы пользователя не трогать.** История диктовок
(`~/Library/Application Support/Cyclop/dictation-history.jsonl`, 155 записей),
записи, установленные приложения. Для проверок делать копии во временной папке.

## Грабли этого проекта

Каждая стоила отдельного раунда ревью — перечитывать перед правками в этих местах.

**`@Published` рассылает подписчикам синхронно, в `willSet`, когда в хранилище
ещё старое значение.** На этом трижды строились дефекты: залипание клавиатуры,
запирание записи, зависимость от порядка двух строк в `NotchViewModel`. Правки
вокруг состояния диктовки проверять трассировкой графа вызовов — тесты этого не
поймают, они не видят исполняемый таргет.

**Ad-hoc подпись пересчитывается каждую сборку**, и macOS считает приложение
новым, отзывая выданные разрешения при внешне включённом тумблере. Поэтому
`bundle.sh` подписывает сертификатом разработчика, если он найден. После смены
способа подписи разрешения придётся выдавать заново:
`tccutil reset Accessibility com.cyclop.app`.

**`Canvas` обрезает по своим границам.** Размытое свечение, дотянувшееся до края
холста, срезается ровной линией. Холст всегда крупнее рисунка.

**Затухание анимации должно гасить яркость, а не только размах** — иначе по краям
остаются прямые неподвижные линии.

**История пишется дозаписью одной строки** через `O_APPEND`. Полная перезапись
стёрла бы поля, которых нет в модели (`source` у архивных записей) — уже ловили.

**Внешний процесс переживает своего владельца.** Обработчики чтения обнулять на
EOF, иначе два источника крутятся вхолостую и съедают по ядру каждый. Отложенный
перезапуск привязывать к поколению процесса.

**`ffmpeg` в macOS нет.** `mlx-whisper` читает аудио, вызывая его из `PATH`, —
на машине без Homebrew это отказ распознавания. Поэтому воркер разбирает wav
сам (`cyclop_dictation/audio.py`) и отдаёт модели сэмплы, а не путь. Проверять
правки в записи и распознавании с урезанным окружением: `env -i PATH=/usr/bin:/bin`.

**`snapshot_download` крутит два байтовых счётчика сразу** — принятое из сети и
записанное на диск, — и оба доходят до полного размера. Сумма по всем полосам
даёт двойной вес и заполняет шкалу на середине; поэтому `Aggregator` берёт
максимум, а не сумму.

**Питону нельзя давать писать внутрь бандла.** Байткод кэшируется рядом с
исходником, а воркер импортирует из `Cyclop.app` — один `__pycache__` ломает
печать подписи, и `spctl` начинает отвечать «a sealed resource is missing or
invalid». Воркер запускается с `-B`, дочерние процессы накрыты
`PYTHONDONTWRITEBYTECODE`, байткод компилируется при сборке.

**Hardened runtime убивает распознавание молча.** Процесс получает SIGKILL
сразу после загрузки модели, без краш-репорта: MLX отображает память, которая
одновременно записываемая и исполняемая. Лечится единственным entitlement —
`allow-unsigned-executable-memory` (именно им, не `allow-jit`; проверено
четырьмя прогонами, см. `Scripts/Cyclop.entitlements`).

**`uv` держит рядом с настоящим питоном симлинк без патч-версии.** `cp -R` по
нему копирует ссылку, а не дистрибутив: `pip` уходит ставить пакеты в
собственный питон `uv`, «рантайм» получается нулевого размера, и видно это не
сразу. `Scripts/runtime.sh` разрешает путь через `pwd -P` и проверяет
`sys.prefix` собранного питона.

## Состояние

Диктовка работает, приложение установлено и подписано сертификатом разработчика.
Воркер отвязан от прежнего приложения и от ffmpeg, питон едет внутри бандла,
модель выбирается и качается из самой вкладки диктовки — приложение
самодостаточно. Следующая работа — публикация образа (`Scripts/dmg.sh` уже
собирает 176 МБ) и проверка на чужой машине. Контекст, решения и
технические находки:
[`docs/superpowers/2026-08-07-handoff-packaging.md`](docs/superpowers/2026-08-07-handoff-packaging.md).

Замеры памяти и методика — [`docs/dictation-memory.md`](docs/dictation-memory.md).
